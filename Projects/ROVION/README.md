# ROVION
Landslide Rescue Rover Project

1. ROVION – Landslide Rescue Rover

ROVION is a search-and-rescue project developed to support rescue operations in landslide-affected environments.

The project focuses on the concept of using an aerial system and a ground rover to identify and verify possible survivor locations in hazardous areas.

My contribution included:

Project planning
Problem analysis
System workflow design
Prototype planning
Technical documentation
Presentation development

ROVION was developed as part of the Smart India Hackathon 2026.
